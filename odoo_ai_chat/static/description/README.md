# Addon Logo/Icon

This folder contains the visual assets for the AI Chat Assistant addon.

## Module Icon

Place your addon icon here as:
- **Filename**: `icon.png`
- **Location**: `/odoo_ai_chat/static/description/icon.png`
- **Format**: PNG
- **Recommended Size**: 256x256 pixels or larger (Odoo will scale it)
- **Background**: Should work on both light and dark backgrounds

This icon will appear in:
- Apps menu
- Module installation page
- Module details view

## Additional Images (Optional)

You can also add screenshots or promotional images:
- `screenshot_1.png`
- `screenshot_2.png`
- etc.

These will appear on the module's description page if referenced in `index.html`.
