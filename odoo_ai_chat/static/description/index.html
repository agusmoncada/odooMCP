🤖 AI Chat Assistant for Odoo v16

Transform your Odoo experience with an intelligent AI assistant that understands your business and can interact with your data. Powered by OpenRouter and featuring integrated MCP (Model Context Protocol) server capabilities.

✨ Key Features

🎯 Instant Access
Click the AI icon in your top menu bar to chat from anywhere in Odoo. No need to switch contexts or open separate applications.
🔧 MCP Server Integration
Built-in Model Context Protocol server allows the AI to interact with your Odoo data intelligently - search, read, create, and update records.
🌐 OpenRouter Powered
Connect to multiple AI models including GPT-4, Claude, LLaMA, and more through a single OpenRouter integration.
💬 Session Management
Create multiple chat sessions, switch between conversations, and maintain complete chat history for future reference.
⚙️ Highly Configurable
Customize AI behavior, select your preferred model, adjust creativity settings, and define custom system prompts.
🔒 Secure & Permission-Based
All operations respect Odoo's security model. Users can only access and modify data they have permissions for.

🚀 Quick Start

  1. Install the module from Apps
  2. Get an API key from OpenRouter
  3. Configure settings in Settings > General Settings > AI Chat
  4. Click the robot icon in the top menu to start chatting!
💡 Tip: Enable "MCP Tools" in settings to allow the AI to interact with your Odoo data for more powerful assistance.

🎯 What Can It Do?

When MCP tools are enabled, your AI assistant can:

  • Search for customers, orders, invoices, and any other records
  • Retrieve detailed information about specific records
  • Create new contacts, leads, or other records
  • Update existing records with your permission
  • Explore model structures and available fields
  • Answer questions about your business data

💬 Example Conversations

You: "Show me the top 5 customers by sales"

AI: Searches your customer records and presents the results

You: "Create a new contact for John Doe at Acme Corp"

AI: Creates the contact and confirms with details

You: "What are my open sales orders?"
