# Logo Image

Upload your logo image here as `logo.png`

## Requirements:
- **Filename**: `logo.png`
- **Format**: PNG (with transparency recommended)
- **Size**: 24x24 pixels (or any size, will be scaled to 24x24 in the interface)
- **Background**: Transparent background recommended for best appearance

## Usage:
This logo will appear in the top systray (top-right corner) next to other Odoo system icons.

The logo is referenced in:
- `static/src/xml/ai_chat_templates.xml` (systray template)
- `static/src/css/ai_chat.css` (styling)
